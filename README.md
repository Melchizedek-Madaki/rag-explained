# RAG, Explained From Scratch

A beginner-friendly, scroll-based visual article that explains
Retrieval-Augmented Generation (RAG) one idea at a time: why chatbots need it,
how keyword and semantic search work, what embeddings and vector databases do,
how documents are chunked, and how the whole pipeline fits together.

Part of the **Explained with MK** series by Melchizedek Madaki.

## Run it locally

```
npm install
npm run dev
```

Then open the address shown in the terminal (usually http://localhost:5000).

## Build

```
npm run build
```

The finished site is the `public` folder.
